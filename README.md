# ChineseCanFly 中国人能飞

一个轻量级 Bukkit 插件——讲中文才飞！

当玩家客户端语言设置为中文时，自动获得飞行权限，生存/冒险模式下也能像创造模式一样双击空格起飞。

## 功能

- **语言检测**：持续监听玩家客户端语言，支持简体中文 (zh_cn)、繁体中文 (zh_tw、zh_hk) 和文言文 (lzh)
- **即时生效**：切换语言后飞行权限立即授予或收回，无需重新进服
- **模式兼容**：创造模式与旁观模式自带的飞行能力不受影响
- **安全落地**：空中被收回飞行权限时免疫摔落伤害
- **无冲突设计**：仅管理由本插件授予的飞行权限，不干扰其他插件

## 安装

1. 下载 `ChineseCanFly-1.0.0.jar`
2. 放入服务端 `plugins/` 目录
3. 重启服务器或执行 reload

**兼容版本**：Spigot / Paper 1.16+

## 构建

```bash
mvn clean package
```

产出文件位于 `target/ChineseCanFly-1.0.0.jar`。

## 工作原理

| 客户端语言 | 游戏模式 | 行为 |
|:---:|:---:|:---|
| 中文 | 生存 / 冒险 | 授予飞行权限 |
| 中文 | 创造 / 旁观 | 不干预（原生飞行） |
| 非中文 | 生存 / 冒险 | 收回飞行权限 |
| 非中文 | 创造 / 旁观 | 不干预（原生飞行） |
